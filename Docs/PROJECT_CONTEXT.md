## CORE_CONCEPT

플레이어가 직접 전투하면서 설치물과 동료를 활용해 적의 진입을 막는 **3인칭 3D 액션 디펜스**입니다.

핵심 방향은 다음과 같습니다.

- 플레이어 액션과 디펜스 배치를 동시에 활용합니다.
- 스테이지 진입 전 무기와 강화를 준비합니다.
- 스테이지 중에는 웨이브를 방어하고 처치 재화로 설치물과 동료를 운용합니다.
- 적은 원칙적으로 플레이어보다 방어 목표를 우선합니다.
- 스테이지별 성공 / 실패 조건과 별 평가를 둡니다.
- 클리어 결과와 탐험 미션을 통해 영구 성장과 해금을 진행합니다.

## CORE_GAME_LOOP

1. 로비에서 스테이지와 난이도를 선택합니다.
2. 무기 1개를 선택하고 영구 강화 / 해금 / 아이템 준비를 진행합니다.
3. 스테이지에 입장하여 준비 시간 동안 설치물을 배치합니다.
4. 웨이브가 시작되면 플레이어 전투, 설치물, 동료를 함께 활용해 방어합니다.
5. 적 처치와 연속 처치로 스테이지 재화를 얻습니다.
6. 웨이브 사이에 재정비하고 필요 시 동료를 고용 / 재고용합니다.
7. 스테이지별 성공 / 실패 조건을 판정합니다.
8. 결과 화면에서 별, 보상, 탐험 미션 진행도를 확인합니다.
9. 로비로 복귀하여 영구 해금과 강화를 진행하고 다음 스테이지를 준비합니다.

넉백은 지속 상태이상과 구분한 강제 이동입니다. 검 기본 스킬은 이동하는 충격파가 아닌 즉시 전방 범위 피해와 넉백을 사용합니다. 캐릭터 애니메이션과 표현 담당 경계는 [ARCHITECTURE.md](ARCHITECTURE.md#responsibility_boundaries)를 참조합니다.

## ECONOMY

### 영구 재화

새 진행의 최초 영구 재화는 300을 기준으로 한 번 지급합니다. 기존 저장 불러오기/게임 재실행/로비 복귀에서는 재지급하지 않습니다. 설정과 생성 계약은 [CURRENCY_SYSTEM.md](Systems/CURRENCY_SYSTEM.md)를 참조합니다.

획득:
- 탐험 미션
- 도감 해금 보상
- 스테이지 클리어 / 별 기록

클리어 보상은 매 클리어마다 이번 확정 점수의 배율을 기본 보상에 적용합니다. 최고 기록 갱신 여부와 무관하며, 최초 별 보상은 스테이지·난이도별 지급 이력으로 별도 계산합니다. 2026-11-04 채택한 기준과 설정 초기값은 다음과 같습니다.

```text
달성률 = min(확정 점수 / 맵·난이도별 기준 점수, 1)
클리어 보상 = floor(기본 보상 × 난이도 배율 × (1 + 최대 점수 추가 배율 × 달성률))
승리 종료 보상 = 클리어 보상 + 미지급 최초 별 보상
```

| 항목 | 채택 기준 / 설정 초기값 |
| --- | --- |
| 기본 보상 / 최대 점수 추가 배율 | 300 / 50%. 정상 0점도 기본 보상 지급, 기준 점수 이상은 최대 배율 유지 |
| 난이도 배율 | 쉬움·보통 100%, 어려움 120%. 점수 배율을 반영한 클리어 보상 전체에 적용한 뒤 소수점 버림 |
| 최초 별 보상 | 2성 100 / 3성 200. 첫 3성은 둘 다 지급, 2성 지급 후 3성은 미지급 200만 지급. 반복 달성은 추가 지급 없음 |
| 패배 / 중도 포기 | 패배 50, 포기는 종료 보상 없음. 둘 다 점수·별 보상 없음 |
| 미션·도감 보상 | 기존 최초 보상 유지. 점수·난이도 배율 적용 제외 |

기준 점수는 KMB의 점수 공식을 변경하지 않는 보상용 설정이며 3개 맵/3개 난이도에 배정했습니다. 기존 최고 별은 해당 단계까지 보상을 지급한 것으로 처리하는 AlreadyPaid 정책을 채택했습니다. 설정은 [재화 시스템](Systems/CURRENCY_SYSTEM.md#종료-보상-계약), 남은 연계는 [점수 보상 TODO](TODO.md#클리어-점수-보상-연결)를 참조합니다.

사용:
- 무기 해금
- 설치물 해금
- 영구 강화
- 사용 아이템 구매

## EXPLORATION_MISSION

확정 방향:

- 미션·난이도별 최초 완료마다 탐험 레벨 +1. 같은 미션도 다른 난이도 최초 완료는 각각 증가
- 미션 완료 즉시 개별 보상 지급
- 탐험 레벨 구간 보상은 별도로 두지 않음
- 누적 처치 단계는 하나의 누적 값을 공유하며 초과 달성분을 다음 단계에도 인정
- 각 단계 보상은 최초 1회만 지급
- 누적 진행도 / 달성 / 보상 지급 여부 저장

초기 조건 종류는 완전 방어, 아이템을 사용하지 않고 클리어, 동료를 참여시키지 않고 클리어, 기본형 처치 30/100마리, 탱커형 처치 20마리, 사망하지 않고 클리어, 어려움 클리어 8종입니다. 완전 방어를 스테이지별로 나눠 미션 10개를 구성했습니다.

추가 집계 기준:

- 미션은 식별 ID·이름·적용 난이도·선행 조건·보상과 조건별 목표를 가집니다. 데이터 구조와 호출 계약은 [MISSION_SYSTEM.md](Systems/MISSION_SYSTEM.md)를 참조합니다.
- 누적 처치·미션 완료·보상은 난이도별로 분리합니다. 적용 난이도가 제한된 미션은 해당 난이도에서만 평가하며 상위 난이도의 하위 난이도 자동 완료는 구현하지 않습니다.
- 플레이어·동료·설치물·화상·맵 기믹의 처치와 보스 소환 적을 인정합니다.
- 실패·포기·재시작해도 누적 처치와 플레이 중 확정된 달성·보상을 보존합니다.
- 준비 단계의 행동은 집계에서 제외하되, 준비 중 고용한 동료도 전투에 참여하면 동료 없이 클리어하는 조건은 실패합니다.
- 아이템 사용 제한은 플레이 중 사용 성공 이력, 사망 제한은 플레이 중 사망 이력으로 판정합니다. 동료 사망·플레이어 부활로 해당 이력을 지우지 않습니다.
- 완전 방어는 스테이지 1 통과 0명, 2 목표 피해 이력 없음, 3 두 조건 모두 충족하여 클리어하는 별도 미션입니다. 회복으로 무피해 이력을 복구하지 않으며 별 3개 여부로 대체하지 않습니다.
- 누적 처치는 처치 직후, 클리어 조건은 최종 승리 확정 시 평가합니다. 잠긴 단계도 누적 기록을 반영합니다.

미션 규칙과 사용 계약은 [MISSION_SYSTEM.md](Systems/MISSION_SYSTEM.md), 도감의 데이터·해금·조회 계약은 [COLLECTION_SYSTEM.md](Systems/COLLECTION_SYSTEM.md)에서 관리합니다. 구현·검증 상태는 각 문서가 연결한 TODO·Test·DONE을 참조합니다.
