# ROADMAP

## PURPOSE

이 문서는 6주 팀 프로젝트의 주차별 개발 목표와 완료 기준을 관리합니다.

세부 구현 항목은 `TODO.md`, 시스템 책임과 담당 경계는 `ARCHITECTURE.md`에서 관리합니다.

## CURRENT_PHASE

- 전체 일정: 6주
- 1~4주차: 기능 / 콘텐츠 개발
- 5~6주차: 폴리싱 / 버그 수정 / 밸런스 / 디테일 보강
- 전체 개발 단계: 미확정 핵심 규격 결정 → 공용 계약 확정 → 핵심 루프 구현 → 콘텐츠 확장 → 통합 검증. 현재 LJ 작업 순서는 아래 실행 순서를 따릅니다.

남은 팀 공통 결정은 [TODO의 미결정 목록](TODO.md#open_decisions)을 기준으로 합니다.

### 현재 LJ 실행 순서

다음 LJ 작업은 **8순위 데이터·콘텐츠**입니다.

1. 실행 시 진행 불러오기 — [코드 반영·정적 확인 완료](DONE.md#2026-11-09-저장입장-흐름-보완). Unity 플레이와 타이틀 UI 연동은 후속.
2. 웨이브 저장·최종 정산 — LJ 코드 반영 완료. KMB의 웨이브 완료 호출 연결과 Unity 저장·정산 검증 후속.
3. 정식 입장·재도전·로비 복귀 — LJ의 보통 우선 선택과 첫 입장 실패 후 같은 선택으로 재진입하는 코드 반영. 실제 맵·난이도 준비 범위와 로비 목록 정합성, 담당자 연결과 Unity 왕복 검증 후속.
4. 다음 스테이지 조회·이동 — LJ 코드 반영과 격리 검증 완료. KMB 맵·난이도 지원 조회, LHJ 결과 버튼과 Unity 통합 검증 후속.
5. 플레이 씬 백업·복원 — LJ 코드 반영과 격리 검증, Firebase Inspector 기본 검증 완료. [정식 씬·화면 연결과 통합 검증](TODO.md#firebase-수동-백업복원)은 후속.
6. 도감 출현 스테이지 조회 — LJ 구현과 Stage 1 보통 기준 로비 Inspector 확인 완료. 실제 도감 상세 연결과 전체 구성 검증은 [도감 TODO](TODO.md#도감--구현-상태와-후속) 참조.
7. LJ 로직 개별 회귀 — 전투·동료·재화·강화·구매·입력의 기본 동작 확인 완료. 저장·정산 실패와 정식 씬·화면 연결 후 검증은 기능별 TODO에서 관리.
8. LJ 데이터·콘텐츠 — 무기·스킬 수치, 동료 고용비·재고용 대기. [도감 문구 반영 완료](DONE.md#2026-11-09-도감-문구-반영).
9. 활 궁극기 홀드·줌 — 확정 입력과 홀드의 관계, 장전 자세·줌과 복귀.
10. 검 궁극기 흔들림 — 타격 시 한 번 재생하고 설정 저장·복원.
11. LJ VFX·사운드 — 셋업 개선, 잔여 출력·수명 확인과 음량 조정.

1~7에서 남은 연결과 추가 검증은 기능별로 진행합니다. 8은 데이터·콘텐츠, 9~11은 후순위 연출입니다. 상세 작업은 [LJ 현재 작업](TODO.md#lj-현재-작업)을 따릅니다.

LJ 로직은 기존 API와 테스트 데이터로 먼저 구현·확인합니다. 정식 맵 입장, 실제 웨이브 완료 저장, 결과·설정 화면을 통한 이동과 전체 플레이 회귀는 담당자 연결 후 검증합니다.

아래 주차별 표는 기존 6주 개발 목표이며 기능별 완료 체크리스트가 아닙니다. 담당 경계는 [ARCHITECTURE.md](ARCHITECTURE.md), 현재 외부 연계는 [LJ_INTEGRATION_GUIDE.md](LJ_INTEGRATION_GUIDE.md)를 참조합니다.
