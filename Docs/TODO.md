- 실제 개발을 막은 오류는 `ERROR.md`에 기록합니다.
- 일정 변경은 `ROADMAP.md`에 반영합니다.
- 책임 / 공용 계약 변경은 `ARCHITECTURE.md`에 반영합니다.
- 기획 범위 / 시스템 규칙 변경은 `PROJECT_CONTEXT.md`에 반영합니다.
- 추천 초기값과 확정 규칙을 구분합니다.
