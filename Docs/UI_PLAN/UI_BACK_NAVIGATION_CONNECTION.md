# ESC·뒤로·취소 연결 — 2026-10-24

## 연결 경로

| 현재 화면 | 복귀 경로 |
| --- | --- |
| 결제 확인창 | 결제 없이 상점으로 복귀 |
| 강화 상세창 | 상점으로 복귀, 이전 선택 카드 복원 |
| 상점에서 연 소모품 목록 | 상점 표시·입력 복원 |
| 인벤토리에서 연 소모품 목록 | 기존 인벤토리 화면으로 복귀 |
| 동료 고용창 | 일시정지 메뉴 유지, 게임 복귀는 하지 않음 |
| 상세 통계 | 결과 화면으로 복귀, 진입 버튼 선택 복원 |
| 재시도 확인창 | 기존 CancelConfirmation 경로로 원래 결과/일시정지 화면 유지 |

## 처리 방식

- ESC 키 조회는 기존 PauseMenuController 한 곳에서만 수행한다.
- 진행 중인 재시도/이동 확인창을 먼저 취소한다. 이어서 결제 확인창 → 소모품 목록 → 동료 고용창 → 상세 통계 순서로 실제 열려 있는 하위 화면을 확인한다.
- 하위 화면 하나를 닫으면 해당 프레임의 처리를 바로 종료한다. 같은 ESC 입력이 상점 닫기/일시정지 해제 등 상위 동작으로 이어지지 않는다.
- 결제 확인창은 기존 CloseConfirmation을 사용하므로 차감하지 않는다. 소모품과 동료 고용도 기존 뒤로/취소 버튼과 동일한 닫기 함수를 사용한다.
- 강화 상세는 기존 Close 경로를 유지하고, 진입 직전 선택한 카드가 다시 활성화되면 해당 카드로 선택을 복원한다. 상세 진입 시에는 뒤로 버튼을 선택하여 비활성 상점 카드에 선택이 남지 않도록 한다.
- 상세 통계는 결과 진입 문맥을 유지한 채 닫고 이전 버튼을 선택한다. 이전 버튼이 없으면 활성 결과 버튼을 선택한다.
- 하위 화면 복귀에서 게임 입력·커서·시간을 별도로 초기화하지 않는다. 기존 일시정지 수명을 유지하며 게임 복귀 시 기존 Resume에서 이전 값을 복원한다.

## 수정 경계와 확인 범위

이번 변경 파일은 기존 UI 스크립트 6개(PauseMenuController, SpellbookCardPreview, ConsumableScreenBinder, CompanionHirePanel, StageResultUiBinder, UpgradeDetailPreview)와 이 문서다. 다른 작업자의 게임 입력/전투/재화/저장 스크립트·씬·프리팹·이미지 및 기존 변경 사항은 수정하거나 되돌리지 않았다.

- 관련 UI 스크립트 6개 단독 컴파일: 오류 없음. 전체 프로젝트 빌드는 하지 않았다.
- 정적 검사: 확인창 우선순위, 하위 화면 닫기 후 즉시 return, 하위 UI의 중복 ESC 조회 없음 확인.
- Unity 실행·포커스·실제 키 입력 검증은 미수행.

남은 실행 확인:

1. 표의 각 화면에서 ESC와 실제 뒤로/취소 버튼을 각각 실행하여 같은 복귀 경로 확인.
2. 결제 취소 시 재화 미차감, 동료 고용창 취소 시 일시정지 유지 확인.
3. ESC를 한 번 누르면 하위 화면 하나만 닫히고 다음 ESC에서만 상위 화면이 처리되는지 확인.
4. 강화 상세·통계 복귀 후 키보드 선택이 숨겨진 버튼에 남지 않는지 확인.
5. 결과/일시정지에서 재시도 확인창을 취소할 때 화면·선택·시간·입력 상태 유지 확인.
