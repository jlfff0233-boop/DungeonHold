# 콤보 HUD 연결 — 2026-10-24

## 반영 내용

- `ComboHudBinder`가 같은 씬의 초기화된 TestScene.Rewards를 찾아 구독한다. 기존 Inspector의 명시적 Rewards 참조는 우선 유지한다.
- 현재 처치 수와 다음 보상 처치 수는 실제 StageRewardController에서 조회한다. 마지막 단계 이후에는 최종 단계 도달로 표시한다.
- 남은 시간은 GetComboRemainingTime으로 표시하고, 게이지는 실제 연결된 ComboData.Duration 대비 남은 시간으로 갱신한다.
- 기존 `RemaingingTimeText` 이름을 보존하면서 자동 연결한다. 기존 ComboText/보상 텍스트와 HUD 배치를 사용하고, 콤보 영역 안에 게이지·단계 아이콘·정적 효과 이미지를 추가한다.
- ComboData의 보상 목록 순서로 단계 외형을 선택한다. 현재 설정은 유지시간 4초, 보상 기준 5/10/20처치다. 이미지의 within10/within20/within30 이름을 보상 기준으로 사용하지 않는다.
- 콤보가 만료되면 숫자·남은 시간·게이지·아이콘·효과를 초기화하고 콤보 영역을 숨긴다.
- OnRewardPaid의 ComboAmount > 0인 실제 지급 성공 이벤트만 알림을 만든다. 연속 지급은 큐에 넣어 한 건씩 표시하고, 같은 도전의 LifeId가 같은 요청은 중복 표시하지 않는다.
- 도전 종료/번호 변경/Rewards 대상 교체/HUD 비활성화 시 큐·중복 기록·이전 알림을 제거한다. 다시 열 때 과거 지급 이벤트를 재생하지 않는다.

## 수정 경계

이번 변경은 `Presentation/UI/ComboHudBinder.cs`, `LHJ/HUD/Canvas_HUD.prefab`의 콤보 연결 필드, 이 문서다. 기존 Canvas_HUD의 무기/Q/E 연결 변경은 보존했다.

Combo/ComboData/StageRewardController/RewardRequest/재화/저장/게임 입력/씬 및 이미지와 .meta는 수정하지 않았다. 일반 Texture2D 리소스를 UI 실행 중 Sprite로 변환하므로 다른 작업자의 Import 설정 변경이 필요하지 않다. 이미지 효과는 정적 표시이며 후반 FX 작업 완료를 뜻하지 않는다. 실제 플레이 씬 HUD 통합도 진행하지 않았다.
