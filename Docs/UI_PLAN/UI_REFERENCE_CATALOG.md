# UI 참고 자료 목록

갱신: 2026-10-10. 기존 22장(R01~R22) + 일시정지 1장(P01) + 새 첨부 45장(R23~R67), 총 68개 PNG 원본을 보관한다. 새 45개는 임시 경로에서 복사한 뒤 원본과 SHA-256 일치를 확인했다.

R 번호는 보관 ID다. **이번 첨부 #1은 R23, #45는 R67**이며 사진 번호와 혼동하지 않는다. 화면 ID S/H/F는 [작업 계획](UI_WORK_PLAN.md)의 제작 단위와 연결된다. 같은 화면의 페이지·선택·튜토리얼 단계는 여러 자료를 한 화면에 연결한다. 각 사진을 독립 씬/프리팹으로 만드는 목록이 아니다.

정지 사진에서 확인한 구성과 제안 동작을 구분한다. 배경의 영상 재생 UI/외부 앱 메뉴는 제작 대상에 포함하지 않는다. 같은 기능의 사진은 복사본이 동일하다는 뜻이 아니다. R06/R07만 기존 원본 해시까지 동일한 것으로 확인되어 있다.

## HUD 예시안 — 2026-10-12 사용자 지정

[인게임 HUD 예시안](UI_References/HUD_Wireframe_2026-10-12.png)은 HUD 정보 배치의 우선 기준이다. 좌상단 플레이어/동료 HP·에너지, 상단 중앙 남은 적/중요 알림, 우상단 웨이브/제한 시간/미니맵, 우측 중간 연속 처치/코인 획득 알림, 좌하단 상점 코인, 하단 중앙 숫자키 아이템 바, 우하단 스킬을 따른다. 다른 새 구성 예시 5장은 참고이며 기존 화면 제작 순서를 바꾸지 않는다. 숫자키 수, 동료 수, 스킬 수, 계산/사용 조건은 그림만으로 확정하지 않는다.

## 자료가 없는 연결 대상

옵션 허브에서 게임플레이·제작진·진행 저장·스크램블 초기화·언어·외부 계정 항목이 보인다. 실제 하위 본문/계정 인증 화면은 제공되지 않았다. 기능/버튼/진입 표면은 계획에 포함하고 해당 본문은 프로젝트 정보로 설계한다. 친구 초대 선택창과 전체 순위표도 진입 근거만 있으며 본문 레이아웃은 후속 설계다.

승리 결과 자료는 확보했다. 실패 결과, 대미지 숫자 스타일, 동료/도감/미션 상세, 무기 Tween의 실제 움직임·시간은 별도 사진/영상이 없다. 기존 프로젝트의 필수 기능은 계속 제작하며 시각 상세만 후속 보완한다.
