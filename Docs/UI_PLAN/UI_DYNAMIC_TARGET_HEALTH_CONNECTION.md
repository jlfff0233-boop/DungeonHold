# 적·동료 HP 및 상태이상 UI 연결 — 2026-10-24

## 반영 범위

- 신규 UI 스크립트 `DynamicTargetHudBinder`를 기존 `LHJ/UIControllers.prefab`에 추가했다.
- 기존 `Canvas_TargetHealth.prefab`를 UI 쪽에서 실행 중 복제한다. 적/동료/전투/상태이상/웨이브/고용 스크립트와 적·동료 원본 프리팹은 수정하지 않았다.
- 기존 HUD의 동료 행을 고용 순서 Z/X 슬롯으로 사용한다. 원본 PlayerStatus/CompanionHudBindings/Canvas_TargetHealth 프리팹 및 이미지/Import 설정은 수정하지 않았다.

## 적 체력바

- 공개된 생성 이벤트가 없어 UI에서 0.2초마다 활성 EnemyCombat을 검색한다. 같은 씬·현재 도전 번호이며 피해를 받을 수 있는 실제 등록 적만 연결한다. 미등록 테스트 오브젝트는 제외한다.
- 생성 감지에는 최대 약 0.2초 지연이 있을 수 있다. 게임 스폰 흐름과 공유 API를 변경하지 않는다.
- Health/StatusEffectController 이벤트에 연결하고 최초 값을 즉시 표시한다. 실제 HP 수치와 화상·감속·기절 상태를 반영한다.
- 체력바는 적의 Collider/Renderer 높이를 따라 월드 위치를 갱신하고 현재 주 카메라 방향을 따른다. 카메라 뒤·화면 밖·HUD 비표시 상태에서는 숨긴다.
- 사망·통과·비활성화·파괴·도전 종료 시 구독을 해제하고 UI를 제거한다. 같은 오브젝트가 재사용되어 RewardLifeId가 달라지면 이전 UI를 버리고 다시 연결한다.
- 대상별 사전으로 중복 생성을 막는다. UI 복제본의 미연결 레거시 표시 컴포넌트와 Raycaster만 중지하며 원본 프리팹은 보존한다.

## 동료 슬롯

- TryGetEntryAt(0/1)과 OnEntryChanged로 실제 고용 기록에 연결한다. 같은 타입 2명도 서로 다른 슬롯과 대상을 사용한다.
- Z/X·동료 종류·배치/전투 대기·생존·사망·재고용 대기/가능 상태와 HP 게이지·수치를 표시한다.
- 재고용 또는 인스턴스 교체 시 이전 Health/StatusEffectController 구독을 해제하고 새 동료에 연결한다. 죽은 동료의 상태이상은 표시하지 않는다.
- 동료 Energy API가 없으므로 기존 샘플 에너지 바는 실행 중 숨긴다. 고용 기록이 없는 행과 2개를 넘는 샘플 행도 숨긴다. 초상화 리소스 자체는 변경하지 않는다.
- 같은 슬롯을 갱신할 수 있는 기존 CompanionHudBindings 아래의 활성 표시 컴포넌트만 실행 중 잠시 중지하며, 새 UI 연결이 비활성화되면 해당 컴포넌트의 원래 활성 상태를 복원한다.

## 확인 범위

- 신규 스크립트 단독 컴파일: 기존 프로젝트·Unity 어셈블리 참조, 오류 없음. 전체 프로젝트 빌드는 미수행.
- 대상 Health/상태이상 공개 이벤트, EnemyCombat의 도전/생명 식별값과 피해 수신 가능 판정, 고용 기록 API 확인.
- UIControllers의 신규 컴포넌트·체력바 프리팹·아이콘 3종·폰트 참조와 기존 결과 UI 컴포넌트 보존을 정적으로 확인.
- Unity 실행·표시 크기/위치·재고용·객체 재사용 동작 검증은 미수행.

## 남은 실행 확인

1. 기존 테스트 씬의 실제 적 생성 후 머리 위 체력바·피해/회복 수치 갱신 확인.
2. 적의 화상·감속·기절 적용/해제와 사망/통과 시 표시 제거 확인.
3. 동료 2명 고용 → 배치 → 피해/회복 → 사망 → 재고용 과정에서 Z/X 슬롯 유지 및 참조 교체 확인.
4. 같은 타입 2명과 재사용 적의 이전 체력/상태이상 잔존 여부 확인.
5. HUD OFF/ON·주 카메라 변경·화면 밖 이동·도전 종료·재시도에서 체력바 중복/잔존 여부 확인.
6. 월드 체력바의 벽 가림·크기와 동료 행의 추가 텍스트/아이콘 겹침을 두 해상도에서 확인.
