# 실제 UI/UX 구성 반영 계획

> 2026-10-12 사용자 정정으로 이 문서의 비HUD 개편안과 9일 일정은 적용하지 않는다. 원래 UI_WORK_PLAN/UI_WEEK1_DAILY_PLAN을 유지하며 실제 구성안은 HUD에만 반영한다. 로비 두 패널 개편, 로비 별 3칸 교체, 마법책 버튼의 강화 버튼 변경은 진행하지 않는다. 현재 기준과 파일 검수 결과는 UI_REVIEW_2026-10-12.md를 따른다. 아래 본문은 이전 제안 보관 자료다.

기준일: 2026-10-12. 사용자가 제공한 실제 구성 6장(메인 로비, 강화, 강화 상세, 인게임, 전투상점, 전투 완료)을 현재 제작 기준으로 삼는다. 기존 게임 레퍼런스는 시각 스타일 참고로 유지한다. 이 문서는 수정 제안과 제작 계획이며 씬/프리팹/코드 변경 또는 기능 확정 기록이 아니다.

## 현재 확인 범위

- MissionSelectLobbyScreen, Canvas_HUD, EquipmentSlot의 저장 파일과 기존 UI 작업 계획을 읽었다. Unity 화면 렌더링이나 플레이 검증은 하지 않았다.
- 기존 공통 카드/슬롯/버튼/팝업, 타이틀/캠페인/난이도/영웅 화면은 재사용 대상이다.
- 강화 목록/상세, 전투상점, 결과 화면의 전용 제작 프리팹은 현재 Assets/04. Prefabs 목록에서 확인되지 않았다.
- 기존 DONE에는 완료 기록이 없어 파일 존재를 외형 검수 완료로 취급하지 않는다.

## 기준 해석

- 와이어프레임의 회색 박스와 민트색 번호/설명은 구성 설명이다. 실제 제품의 색/문구/번호로 그대로 제작하지 않는다.
- 슬롯/행/카드의 그림상 개수는 배치 참고다. 실제 콘텐츠 수와 표시 가능한 개수는 구분한다.
- 최신 자료가 다루는 여섯 화면은 이 배치를 우선한다. 타이틀/설정/도움말/팝업 등 자료에 없는 기존 항목은 유지하며, 협동/랭킹/계정 등 확장 화면은 우선순위를 뒤로 둔다. 자료에 없다는 이유로 폐기하지 않는다.
- 강화 코인과 상점 코인은 서로 다른 표시 부품/자리로 준비한다. 영구/스테이지 재화와의 실제 대응은 게임 담당 규격으로 확정한다.
- 현재는 전체 외형 우선. 버튼/전환/입력/실데이터 연결과 FX는 이후 단계다.

## 제작 순서와 작업 예산

아래 9일/72시간은 하루 8시간 기준의 재작업 포함 임시 예산이며 기존 총 6주 안의 남은 시간에 배정한다. 새 6주를 추가하지 않는다. 현재 누적 작업 시간이 불명확하므로 최종 종료일을 확정하지 않는다. 보조 화면은 별도 예산이 필요하다.

| 단계 | 예산 | 산출물 |
| --- | --- | --- |
| 1. 로비 개편 | 8시간 | 스테이지 목록, 클리어 정보, 맵 설명/미리보기 페이지, 강화 코인/플레이/강화 진입 |
| 2. HUD 개편 | 16시간 | 플레이어+동료 상태, 남은 적, 웨이브/시간, 중요 알림, 미니맵 자리, 콤보/재화, 아이템 바, 스킬 |
| 3. 강화 목록 | 8시간 | 뒤로, 좌측 카테고리 탭, 세로 카드 그리드, 위/아래 표시, 강화 코인 |
| 4. 강화 상세 | 8시간 | 이름/설명/이미지, 강화 해금까지 남은 조건, 강화 가능한 항목 카드, 강화 코인/뒤로 |
| 5. 전투상점 | 8시간 | 상단 이번 플레이 적 목록, 좌측 상세, 분류 탭, 아이템 그리드, 하단 현재 장착 바/뒤로 |
| 6. 전투 완료 | 8시간 | 점수, 승리/실패 영역, 별 1~3, 목표 달성도 목록, 강화 코인, 업그레이드 진입 |
| 7. 외형 통합 검수 | 16시간 | 리소스/폰트 적용, 표시 상태와 해상도 검수, 기존 팝업/가이드 대상 위치 수정、완료/미완료 기록 |

각 단계에서 기존 프리팹과 참조를 먼저 재사용한다. UI 계층과 Inspector 수정은 실제 구현 요청 단계에서 수행한다. 현재 계획만으로 새 화면 제어기나 공용 계약을 작성하지 않는다.

## 핵심 화면별 표시 검수

- 로비: 선택/잠금/기록 없음, 긴 맵 설명, 페이지 첫/끝, 재화 긴 숫자.
- HUD: 동료 없음/여러 명/사망, HP/에너지 부족, 준비/전투, 긴 알림, 슬롯 선택/잠금/부족, 스킬 준비/쿨타임. 중요 알림은 조준 및 전투 시야를 가리지 않는지 확인.
- 강화 목록/상세: 미해금/해금 조건 진행/구매 가능/재화 부족/최대 강화, 빈 분류, 긴 설명.
- 전투상점: 이번 플레이 적 없음/여러 종, 아이템 및 적 상세, 필터 선택, 장착/미장착/고정 슬롯. 구매/판매/배치/장착의 실제 허용 단계는 연결 때 반영.
- 전투 완료: 승리/실패, 별 1/2/3, 목표 미달/달성/기록 없음, 보상 없음/있음. 왼쪽 위의 무표기 박스와 복귀/다음/재시도 버튼은 제공 자료만으로 의미를 확정하지 않는다.
- 공통: 1920×1080/1280×720, 긴 한글, 잘림/겹침, 일반/선택/비활성 외형, Root를 끌 때 전체 숨김.

## 이후 남은 보조 UI

1. 기존 타이틀/캠페인/난이도/영웅 화면의 외형 검수.
2. Pause, 도움말 질문, 재시도/나가기 확인창과 필요한 가이드 단계.
3. 옵션 허브, 소리/그래픽/키/게임플레이 설정, 제작진.
4. 적 도감, 동료 상세/고용/강화, 탐험 미션/탐험 레벨 표시. 강화 카테고리 또는 맵 정보에 포함할 수 있는 항목은 중복 화면을 만들지 않는다.
5. 보스/대상 HP, 설치/판매 안내, 조준점과 작은 획득/달성 알림.
6. 결과 통계와 별도 도움말 페이지.
7. 협동/세션/순위/계정/환불/분기 강화 등의 기존 확장 계획은 새 핵심 화면 뒤에서 범위와 실기능 지원을 재확인.

전투상점은 기존 인벤토리 S09 구성, 강화 목록은 마법책 S10 구성, 강화 상세는 S11, 결과는 S12를 재사용하는 제작 단위로 생각한다. 같은 목록을 별도 화면으로 중복 제작하지 않는다. 별도 영구 상점이 필요한지는 게임 규격에 맞춰 판단한다.

## 연결 전에 필요한 합의

- 강화 코인/상점 코인의 실제 자원, 획득/소비 규칙.
- 동료 상태 표시 항목과 최대 동시 인원.
- 아이템 바 슬롯 수와 숫자키 변경 대상. 기존 스테이지 중 무기 고정 규칙을 자동 변경하지 않는다.
- 강화 분류/단계/항목 수와 해금 조건. 상세 그림의 4개 카드가 분기 강화를 뜻한다고 단정하지 않는다.
- 맵 정보 페이지 내용, 목표 달성도와 별 평가 데이터.
- 전투 완료 화면 복귀 버튼 의미, 실패 시 별/보상 표현.
- 미니맵 표시 데이터와 필요 시 방어 목표 지표의 위치. 새 HUD에 방어 목표가 명시되지 않았어도 기존 실패 조건에 필요한 정보를 삭제하지 않는다.

합의가 필요한 값은 외형 제작 동안 임시 데이터로 표시할 수 있다. UI가 보상/별/구매/승패를 직접 판정하지 않는다.
