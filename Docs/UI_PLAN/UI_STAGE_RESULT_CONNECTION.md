# 결과·상세 통계 UI 연결 — 2026-10-24

## 변경 범위

- 새 `Presentation/UI/StageResultUiBinder.cs`를 기존 `LHJ/UIControllers.prefab` 루트에 연결했다. 결과 화면을 닫아도 관측과 종료 이벤트 구독이 유지되며, 씬 파일은 변경하지 않았다.
- `PauseMenuController`에는 최종 결과 전용 `RequestStageResultRetry` 진입점만 추가했다. 기존 현재 웨이브 재시도와 구분하여 같은 확인 팝업을 거쳐 전체 씬을 다시 불러온다.
- Stage1Controller의 HasFinished/HasSucceeded/StarCount/FinalPassedCount와 Hero의 실제 부활 소진 이벤트를 사용한다. UI가 통과 수로 승패를 새로 판정하지 않는다.
- 기존 WaveSummaryHudBinder는 결과 화면을 찾은 경우에만 실행 중 중지한다. 모든 웨이브 종료 요약을 최종 승리로 표시하지 않는다. 기존 스크립트 자체는 수정하지 않았다.

## 종료 및 정산

1. UI 관측 중 도전별 콤보 최고값과 실제 OnRewardPaid 지급액을 보관한다. 지급액은 StageId/LifeId로 중복 제외하며 재화 잔액 차이로 추정하지 않는다.
2. 결과 판정 시 처치·통과·사용 아이템 수·관측 시간·관측 지급액을 UI 스냅샷으로 보관한다. LateUpdate는 TestScene의 정리보다 먼저 실행한다.
3. 실제 승패가 확인되면 기존 `TestScene.RequestEndStage(stageId, false)`를 요청한다. 이미 종료 처리 중이면 재요청하지 않는다. UI에서 지급·소비·저장·게임 모듈 초기화를 별도로 수행하지 않는다.
4. OnStageEndProcessed의 실제 완료 결과로 정산 완료/실패를 표시한다. 완료 후 사용 아이템 수는 LastStageUsedItemCount로 확인한다.
5. 실패하면 `정산 재시도` 버튼을 표시한다. 정산 전 실패는 종료 요청을 다시 하고, 정산 후 정리 실패는 TryCompleteStageCleanup만 호출한다. 자동 재시도나 성공값 대체는 하지 않는다.
6. 승패 API가 없고 전체 웨이브 완료만 확인된 경우 승패 미확인·정산 미요청으로 표시한다. 이 경우 UI에서 최종 종료를 임의로 확정하지 않는다.

## 화면 표시와 이동

- 결과 화면: 실제 승패·정산 상태·별점·영구 재화 잔액·처치/통과/아이템 사용/최대 콤보·관측 지급액을 표시한다.
- 점수/최고 기록/신규 장비 해금 등 제공 API가 없는 샘플 카드는 숨긴다.
- 통계 화면: 처치·통과·최대 콤보·관측 진행 시간·관측 콤보 보너스를 연결한다. 총 피해·직접/함정별 처치·설치/철거 수·미션/최고 기록 등 API 없는 ValueText는 `미집계`로 표시한다.
- 시간은 UI가 관측한 게임 시간이며 공식 완료 시간으로 표시하지 않는다. 지급액도 이 UI가 이벤트로 관측한 값이라는 문구를 붙인다. 스테이지 재화는 종료 시 버려지므로 영구 재화 보상으로 설명하지 않는다.
- 상세 통계 버튼으로 통계에 진입하고 기존 뒤로/닫기 버튼으로 결과 화면에 복귀한다.
- 재시도는 기존 확인 팝업 이후 씬 전체 재시작이다. 상점/캠페인 이동은 기존 PauseMenuController의 복귀 문맥을 사용하며 정산 완료 후 활성화한다.
- 결과 화면이 열리면 기존 HUD를 숨기고 활성 플레이어 InputHandler만 일시 중지한다. 새 도전/웨이브 재시작 때 이 UI가 중지한 입력만 복원하고 이전 스냅샷을 초기화한다.

## 보존 및 검증

다른 담당자의 Stage1Controller/WaveController/TestScene/Hero/보상/재화/저장/설치물/씬/이미지와 기존 변경 중인 상점·HUD 파일은 수정하지 않았다. 기존 결과·통계 프리팹의 저장된 배치/스크롤/이미지와 Canvas_Screens도 수정하지 않았다. 런타임에는 이번 연결 대상 버튼의 전환 이벤트만 교체하며 컴포넌트 파괴 시 원래 이벤트를 복원한다.

- 변경한 UI 스크립트 두 개의 단독 컴파일: 기존 프로젝트 어셈블리·Unity 참조 사용, 오류 없음. 전체 프로젝트 빌드는 하지 않았다.
- UIControllers 프리팹의 새 컴포넌트 GUID/루트 참조와 기존 UI-MapTest 중첩 프리팹 연결을 정적으로 확인했다.
- Unity 실행·화면 배치·실제 정산 실패 주입 검증은 수행하지 않았다.

남은 실행 확인:

1. 스테이지 1 성공/통과 한도 실패/플레이어 부활 소진 각각의 실제 결과·별점 확인.
2. 마지막 처치와 콤보 지급이 같은 프레임에 발생할 때 최종 관측 지급액 반영 확인.
3. 정산 실패 및 정산 후 정리 실패에서 성공 미표시, 이동 차단, 수동 재시도 확인.
4. 결과 → 상세 통계 → 결과 → 상점/캠페인 → 결과의 스냅샷 유지 확인.
5. 전체 씬 재시작 확인 팝업 취소/확인, 이전 통계·입력·HUD 상태 초기화 확인.
6. 추가한 요약/통계/정산 재시도 버튼과 기존 메뉴의 겹침·가독성 확인.
