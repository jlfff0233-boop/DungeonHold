# 무기·스킬·궁극기 HUD 개별 연결 — 2026-10-24

## 변경

- 신규 UI 컴포넌트 `PlayerWeaponSkillHudBinder`를 기존 `Canvas_HUD.prefab`에 추가했다. 실제 플레이 씬에 새 HUD를 배치하거나 씬 간 HUD를 통합하지 않았다.
- 같은 씬에서 초기화가 완료된 TestScene의 현재 Hero를 조회한다. 현재 `Hero.WeaponData.WeaponType`으로 검·활·지팡이 이름과 무기 아이콘을 표시한다.
- Q 슬롯은 `Hero.SkillCaster`와 `WeaponData.SkillData`, E 슬롯은 `Hero.UltimateCaster`와 `WeaponData.UltimateData`를 각각 사용한다.
- 도전 진행 중에는 사용 중 → 남은 쿨타임 → 에너지 부족 → 준비/사용 불가 순서로 표시한다. 최종 사용 가능 여부는 각각 `CanUseSkill`/`CanUseUltimate`로 판단한다.
- 미초기화 상태에서는 연결 대기, 도전 전후에는 입장 전으로 표시한다. 연결 데이터가 없으면 연결 필요를 표시한다.
- 기존 Q/E 상태 텍스트를 재사용하고 자동 글자 크기를 적용했다. 무기 슬롯 위에 현재 무기 이름 텍스트만 추가한다.
- HUD를 다시 열 때 현재 Hero/무기/쿨타임을 재조회하며, 비활성화 시 이전 이름·아이콘·상태 텍스트를 지운다.

## 아이콘과 기존 작업 보존

- 검·활·지팡이의 무기/Q/E 텍스처 9개를 UI 컴포넌트의 무기별 목록에 연결했다.
- 다른 작업자가 추가 중인 이미지와 .meta를 수정하지 않았다. 일반 텍스처를 Sprite로 바꾸는 Import 변경 대신 UI에서 런타임 Sprite를 생성·보관하고, UI 파괴 시 생성한 Sprite만 정리한다.
- 기존 PlayerSkillHudBinder/PlayerUltimateHudBinder 소스는 변경하지 않았다. 새 연결이 활성일 때 같은 HUD 안의 활성 레거시 표시 컴포넌트만 잠시 중지하고, 비활성화 시 원래 활성 컴포넌트를 복원한다.
- Hero/WeaponData/SkillCaster/Energy/입력·전투·저장·씬 및 기존 변경 중이던 상점/강화/인벤토리/이미지 파일은 수정하지 않았다.

## 확인 범위

- 신규 스크립트 단독 컴파일: 기존 프로젝트 어셈블리와 Unity 참조 사용, 오류 없음. 전체 프로젝트 빌드는 하지 않았다.
- 기존 프리팹 계층의 WeaponSlots/Weapon 및 SkillRoot의 Q/E Icon/CooldownText 경로 확인.
- Canvas_HUD의 신규 컴포넌트, 무기 3종·텍스처 9종·폰트 GUID 및 로컬 ID 중복 정적 검사.
- Unity 실행·이미지 크기·텍스트 배치 검증은 미수행.

## 남은 실행 확인

1. 기존 테스트 씬에서 검·활·지팡이로 각각 입장하고 무기 이름 및 Q/E 아이콘 확인.
2. Q/E 각각 시전 중 → 쿨타임 → 준비로 바뀌는지 확인. 한 슬롯의 쿨타임이 다른 슬롯에 표시되지 않아야 한다.
3. 에너지를 각 스킬 비용 미만으로 만든 뒤 부족 표시, 회복 후 실제 사용 가능 표시 확인.
4. 기절·사망·부활 등 게임의 실제 행동 제한에서 사용 불가 표시 확인.
5. HUD OFF/ON, 도전 종료·재시도 및 다른 무기 입장에서 이전 표시가 남지 않는지 확인.
6. 원본 아이콘의 배경/비율과 무기 이름의 기존 슬롯·주변 HUD 간 겹침 확인.
