# UI 저장 파일 검수 및 다음 작업

기준: 2026-10-12 사용자 최종 요청. 기존 UI_WORK_PLAN/UI_WEEK1_DAILY_PLAN의 제작 순서를 유지한다. 새 구성 예시 6장은 참고 자료로 사용하며 **HUD만 예외적으로 [인게임 예시안](UI_References/HUD_Wireframe_2026-10-12.png)의 정보 배치를 우선 기준으로 따른다.** 나머지 화면의 레이아웃을 일괄 변경하거나 6화면 우선 제작 일정으로 재편하지 않는다.

## 확인 범위

View.unity, Assets/04. Prefabs의 UI 프리팹, BMDOHYEON_ttf SDF 에셋/참조를 읽기 전용으로 확인했다. 사용자의 후속 요청으로 저장 파일을 다시 확인하여 아래 상태와 다음 순서를 갱신했다. Unity 실행/실제 표시/클릭/빌드는 검수하지 않았다. 씬/프리팹/코드는 수정하지 않았다.

## 유지할 항목

- MissionSelectLobbyScreen의 MissionListRoot 64/-170/260×740, MissiionPreviewRoot 380/-170/600×700, SummaryPanel 우상단 -64/-56/560×270, PageArea 1040/-380/816×470은 기존 25절의 큰 배치와 일치한다.
- 원래 포털/미션 Preview, 설정 요약, 플레이/취소, 마법책 진입, 5칸 레퍼런스 평가 외형을 유지한다. 게임의 실제 별 판정은 연결 단계에서 데이터에 맞춘다.
- MissionSelectLobbyScreen, DifficultyPlayerScreen, HeroSelectScreen, Canvas_HUD의 View 씬 프리팹 참조가 존재한다.
- 한글 폰트 에셋은 4096×4096, Point Size 77, Static으로 저장되어 있다. 주요 화면에 Font Asset 참조가 적용되어 있다. 모든 문자의 수록/가독성은 별도 확인 대상이다.
- TitleScreen 메뉴는 그룹 480×232, 버튼 3개 각 480×64, 간격 20으로 저장되어 있다.
- HUD의 PlayerStatus, StageStatus, Loadout은 전체 Stretch/여백 0/Scale 1이다. 동료, 남은 적, 중요 알림, 미니맵, 콤보, 스킬, 아이템 바의 그룹과 주요 자식이 존재한다. 기본 그룹을 다시 만드는 단계로 되돌리지 않는다.

## 수정할 항목

### 1. TMP 폰트와 머티리얼 불일치

BMDOHYEON Font Asset을 참조하면서 LiberationSans SDF 머티리얼을 참조하는 TMP가 있다.

| 파일 | 불일치 TMP 수 |
| --- | ---: |
| CampaignModeScreen | 21 |
| DifficultyPlayerScreen | 12 |
| HelpPromptRoot | 4 |
| HeroSelectScreen | 22 |
| MissionSelectLobbyScreen | 7 |
| SelectionCardVertical | 3 |
| Canvas_HUD | 2 |

Inspector의 TMP Material Preset을 BMDOHYEON_ttf SDF에 포함된 기본 머티리얼로 교체한다. 기존 LiberationSans 머티리얼 자체는 수정하지 않는다. 공통 프리팹부터 수정하고 개별 화면의 Override가 남는지 확인한다. 위 수는 프리팹별 저장 항목 수이며 중첩 부품으로 인한 중복 가능성이 있어 고유 화면 글자 수로 합산하지 않는다.

Canvas_HUD의 해당 두 항목은 ComboText와 CoinGainText다. TitleScreen과 KeyHint에는 같은 불일치가 없다. 새 H03 제작 중에는 KeyHint의 기존 한글 Font Asset/머티리얼 조합을 유지한다.

### 2. 로비 목록 상태

MissionRow 7행의 상단왼쪽 앵커/Pivot, Y 0/-104/-208/-312/-416/-520/-624, 번호 1~7, 썸네일 및 선택 테두리 Scale 1은 저장되어 있다. 현재 선택 테두리는 1/4/5/6/7번이 ON이다. 여러 상태 비교용이면 유지할 수 있고, 하나를 선택한 기본 시안으로 저장할 때는 하나만 ON으로 정리한다. 실제 해금/선택 판정은 연결 단계 과제다.

Viewport/Content, 중앙 미리보기의 점수·이름, 친구 페이지와 두 기록 행/이름/기록의 배치는 수정되어 있다. 6번 행 MissionRow01 (5)의 Dim에는 Image가 없고 LockedGroup 부모에 검정 Image가 있다. 다른 행과 구조를 맞출 때 이 검정 Image 설정을 Dim에 옮기고 부모 Image만 제거한다. 현재 부모가 암막을 그릴 수 있으므로 표시 실패로 단정하지 않는다.

현재 PartyPageRoot OFF/FriendsPageRoot ON은 친구 페이지 시안 저장 상태다. 기본 솔로로 저장할 때 Party ON/Friends OFF, SoloHeroPreviewImage ON, WaitingText/CoopPlayerList OFF, PlayerTypeValue 솔로로 설정한다. 친구 페이지 검수 시에는 반대로 바꾼다. 현재 설정을 구조 오류로 판단하지 않는다.

### 3. 남은 외형 마감

Title 로고, 동료 초상, 아이템/스킬 아이콘, 미니맵 MapImage 등에 Sprite=None 자리 표시가 남아 있다. 임시 문구·숫자·아트 교체와 실제 표시 확인은 마감 목록으로 유지한다. Canvas_HUD/Test는 현재 OFF다. 아이템 바에는 선택/잠금/비용 부족 상태용 자식이 아직 없으므로 H02 상태 마감도 남아 있다.

미니맵의 마커 세 개는 흰색/12×12/좌표 0,0이라 겹치는 저장값이다. 정적 샘플을 만들 때 색/위치를 구분한다. 콤보 Root는 현재 OFF이므로 외형 검수할 때만 켜서 확인한다. 동료 HP/에너지의 색상과 0/일부/가득 상태, 서로 크기가 다른 스킬 두 칸도 시안에 맞춰 확인한다.

### 4. HUD 부모 및 새 구성

StageStatus, PlayerStatus, Loadout의 전체 화면 Stretch 수정은 저장되어 있다. 기존 앵커/좌표를 초기화하거나 큰 그룹을 다시 만들지 않는다.

현재 HUD 그룹은 사용자의 인게임 예시안에 해당하는 정보 영역을 갖추고 있다. PassedEnemy 통과수는 남은 적으로 재사용하지 않고 기존 방어 목표 정보도 유지한다. 후속 저장에서 H03의 PreparationHintRoot/DefenseHint/현재 이름 StarWaveHint/SellHint와 B/G/E 문구·좌표가 확인되었다. 생성 단계는 진행됐으며 KeyBox의 흰 배경/흰 글자 대비, 설명 색, 원본 루트 장식의 인스턴스별 표시 차이, 기본 안내 OFF 상태의 마감이 남아 있다. KeyHint 공통 원본의 세 그래픽은 아직 Raycast ON이며 H08 인스턴스 세 개는 원본 장식을 제거한 Override를 갖고 있다. 자세한 설정은 UI_WORK_PLAN 27~28절을 따른다.

H04는 후속 저장에서 ImportantNoticeRoot의 상단중앙 (0,-220)/560×112 배치가 반영되어 Objective와의 Rect 영역 겹침은 해소되었다. NoticeText는 '전투 시작!'/40/흰색/알림 ON인 한 샘플 상태이며 카운트다운/다음 웨이브 수동 검수 완료 여부는 파일만으로 알 수 없다. Overlay Canvas 루트의 저장 Scale 값만으로 숨김 오류나 강제 수정 대상으로 판단하지 않는다.

H08은 최신 후속 저장에서 PlacementGuideRoot와 StateText/ReasonText, RotateHint/ConfirmHint/CancelHint의 생성 및 28절 배치가 확인되었다. StateText는 '설치 가능'/흰색, ConfirmHint 키/설명도 흰색, Root는 ON이다. ForbiddenIcon은 현재 Sprite=None인 흰색 Image/ON으로 금지기호 외형이 아직 없다. 가능 시안 색/금지 OFF/기본 Root OFF, 불가 시안과 두 해상도 확인은 마감 대상이다. 구조가 없는 상태로 되돌리지 않는다.

GuideOverlayRoot.prefab의 공통 부품 및 한글 폰트/기본 Material은 있다. 제목 흰색·Left/Top, 장식 흰색, BodyPanel 흰색/Alpha0.392/Raycast ON, ProgressText Raycast ON은 보완 대상이다. 최신 View.unity에는 가이드 인스턴스 참조가 없고 Canvas_Popup은 프리팹 인스턴스/OFF다. Canvas_Popup의 직계 자식 PopupRoot 아래에 DimmedBackground/MenuTextButton이 있다. 가이드는 Canvas_Popup 직계 자식으로 한 번 배치하고 PopupRoot를 숨겨 확인한다. 목표·재화 추가 안내는 아직 없다. 기초 가이드 전용 자식·배치·문구는 씬 Override로 저장하고 공통 원본에 Apply All 하지 않는 방법을29절에 안내했다.

## 다음 순서

1. H08은 기존 생성물을 유지하고28절의 가능 시안 색/기본 숨김을 정리한다. 다음 새 작업은 기존7일차 기초 가이드 한 화면에 목표·재화·장비 바 설명을 함께 배치하는 것이다. [UI_WORK_PLAN 29절](UI_WORK_PLAN.md#29-다음-새-작업--hud-기초-가이드-한-화면-마감)을 따른다.
2. 그다음 기존7일차 전체 검수 시간에 H02 슬롯 상태, H08 금지기호/불가 시안, KeyHint 대비/장식, TMP Material Preset, S13 표시 시안과 정적 아트/문구를 마감한다. H04의 기본 시안 복원/상태 확인은27절을 참고한다.
3. 1920×1080과1280×720에서 일반/준비/판매/설치/가이드 및 각 화면의 상태를 표시 확인하고 프리팹/View를 저장한다. 직접 확인된 항목만 완료 기록한다.
4. 기존2주차 인벤토리 → 마법책 → 강화 상세 → 결과/통계 → 설정/도움말 및 나머지 UI 순서를 유지한다.

전체 UI 외형 완료 후 버튼/화면 전환/데이터 연결을 진행한다. FX도 전체 UI 외형 이후 시작한다. 실제 작업 시간에 맞춰 기존 총 6주 안에서 예산을 조정하며 새 6주나 별도9일 일정을 추가하지 않는다.
