# 동료 고용 UI 연결 — 2026-10-24

**2026-10-26 변경:** 사용자 요청으로 PauseMenuRoot의 CompanionHirePanel 연결을 제거했다. Pause 메뉴에서 동료 고용 버튼과 전용 고용 화면을 생성하지 않는다. 아래 내용은 기존 연결 기록이며 현재 Pause 메뉴에는 적용되지 않는다. 인게임 6~8번 고용 퀵슬롯은 유지한다.

## 반영 범위

- 신규 UI 컴포넌트: `Assets/02. Scripts/Presentation/UI/CompanionHirePanel.cs`
- 연결 위치: `Assets/04. Prefabs/LHJ/PauseMenu/PauseMenuRoot.prefab` 루트.
- 일시정지 메뉴에 `동료 고용` 버튼을 추가한다. 전용 화면은 처음 열 때 생성하며 기존 일시정지 메뉴의 입력 차단·커서·시간 수명을 따른다.
- 검사·궁수·마법사의 기본 HP/공격력, 신규 고용/재고용 비용을 고용 데이터 맵에서 조회한다. 강화가 적용된 최종 능력치로 표시하지 않는다.
- 신규 고용은 `TryHire`, Z/X 슬롯의 개별 재고용은 `TryRehire`를 사용한다. UI에서 재화를 별도로 차감하거나 동료를 생성하지 않는다.
- 고용 기록 순서대로 Z/X 슬롯에 배치 대기·전투 대기·생존·사망 연출·재고용 대기·재고용 가능 상태를 표시한다.
- 재화 부족·2명 제한은 버튼에 표시한다. 실제 요청 거절은 컨트롤러 반환 결과를 표시한다.
- 뒤로는 일시정지 메뉴로 돌아간다. 일시정지 메뉴가 비활성화되면 고용 화면도 닫고 구독을 해제한다. 도전이 종료되거나 교체되어도 닫는다.
- 기존 일시정지에서 시간을 멈추면 재고용 대기시간도 멈춘다. UI가 대기시간을 임의로 진행시키지 않는다.

## 보존 범위

고용/재화/저장/입력/전투 스크립트와 씬, 기존 변경 중인 상점·강화·Canvas_Screens 및 UI 이미지 파일은 수정하지 않았다. 실제 플레이 씬의 HUD 통합은 진행하지 않았다.

## 확인 및 남은 실행 검증

신규 스크립트 단독 컴파일과 프리팹의 컴포넌트·맵·폰트 참조를 확인한다. 전체 프로젝트 빌드 및 Unity 실행 검증은 수행하지 않는다.

Unity 실행 확인 순서:

1. 도전 시작 후 ESC → 동료 고용. 검사/궁수/마법사의 비용과 스테이지 잔액 표시 확인.
2. 동료 고용 후 잔액 1회 차감, Z/X 순번 표시, 최대 2명 제한 확인. 같은 타입 2명도 허용한다.
3. 뒤로 → 일시정지 메뉴 → 계속. 준비 중 고용했다면 기존 Z/X 배치 동작 확인.
4. 동료 사망 후 연출 종료·재고용 대기 확인. 시간을 진행한 후 메뉴를 다시 열어 해당 슬롯만 재고용되는지 확인.
5. 재화 부족·생성 공간 부족·고용 불가 단계의 실패 표시와 실패 시 미차감 확인.
6. 메뉴 닫기·다시 열기·재시도·도전 종료 시 이전 동료 상태와 창이 남지 않는지 확인.
